   - `ism-frappe/ism/payments/erpnext_bridge.py`: Enforces `_REFUND_STATUS_PRECEDENCE` in `_handle_refund_webhook_event` so out-of-order `refund.created` (`PENDING`) events never regress `COMPLETED` refunds or zero out `refunded_amount`; validates `currency == 'CAD'` before crediting refunds (flagging non-CAD refunds for manual review); ignores delayed `PENDING`/`APPROVED` webhooks in `reconcile_and_post_square_payment` across all 6 terminal transaction statuses (`Posted`, `Failed`, `Voided`, `Partially Refunded`, `Refunded`, `Reconciliation Error`).

   - Regression tests added in `ism-frappe/ism/tests/test_payments_erpnext_bridge.py` and `ism-frappe/ism/tests/test_comms_telnyx_and_webhooks.py`.
